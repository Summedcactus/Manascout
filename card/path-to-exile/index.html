When was Path to Exile first printed?

◇

Path to Exile was first printed in Conflux in 2009. The original card is Conflux collector number 15 and features artwork by Todd Lockwood.

Since that first release, Path to Exile has become one of Magic's best-known one-mana white removal spells and has accumulated a large range of reprints, promotional versions and alternative artwork.

MANASCOUT GUIDE

One white mana for one of Magic's cleanest removal spells

◇

Path to Exile is a one-mana white instant that exiles a target creature.

In exchange, that creature's controller may search their library for a basic land and put it onto the battlefield tapped.

That creates the defining Path to Exile trade-off: extremely efficient permanent creature removal in exchange for giving the opponent access to an extra land.

Because exile can answer creatures that are difficult to deal with through damage or destruction, Path has remained a recognisable white interaction spell across multiple eras of Magic.

WHY PATH?

Why is Path to Exile so widely played?

◇

Path to Exile combines low mana cost, instant speed and exile-based removal in a single card.

Exiling the creature rather than destroying it can prevent death triggers, regeneration and many graveyard-based plans from turning ordinary removal into an advantage.

The drawback matters: the opposing player may receive a basic land, potentially accelerating their mana development.

That tension is part of what makes the card memorable. Path is powerful because the removal is so efficient, but using it well can depend on whether the creature you are answering is worth giving its controller an additional land.

FIRST PRINTING

The original Conflux Path to Exile

◇

Path to Exile first appeared in Conflux in 2009.

The original printing is an uncommon, carries collector number 15 and uses artwork by Todd Lockwood.

If you specifically want the first Path to Exile rather than a later reprint, the Conflux card is therefore the version to look for.

It also represents Path before years of Commander products, Masters sets, promotional releases and premium treatments transformed it into a card with a much broader visual history.

PATH TO EXILE REPRINTS

What changes between Path to Exile printings?

◇

Path to Exile has been reprinted across numerous Magic products since Conflux, including supplemental sets, Commander products and premium releases.

The rules function may remain familiar, but the card itself can vary through artwork, frame treatment, set symbol, foil availability, promotional styling and borderless presentation .

That makes Path particularly useful for ManaScout-style comparison: a player who only needs efficient removal can choose a straightforward reprint, while someone upgrading a favourite deck has far more visually distinctive options.

PROMO PRINTINGS

Path to Exile promo versions

◇

Path to Exile began receiving promotional treatment very early in its life, with promo versions appearing alongside its growing reputation as efficient white removal.

Promotional printings can be especially interesting for collectors because they may combine alternative artwork, foil treatment or event-specific presentation without changing the card's underlying function.

For a card with as many ordinary reprints as Path to Exile, a promo can offer a way to keep the recognisable spell while choosing something that feels less like a standard deck copy.

SECRET LAIR

Path to Exile Secret Lair versions

◇

Path to Exile has become a recurring choice for Secret Lair, giving the card several of its most visually unusual versions.

Secret Lair x Arcane included Path to Exile as part of the 2021 League of Legends: Arcane collaboration, using imagery from the animated series for a dramatically different interpretation of the card.

The same Secretversary release also included Fblthp: Completely, Utterly, Totally Lost, where Path to Exile formed part of a five-card borderless panorama illustrated by Marija Tiurina.

Those releases show why Path is especially interesting as a printing guide: the same one-mana removal spell can range from its traditional Conflux presentation to art-driven crossover and borderless collector versions.

2026 SPOTLIGHT

Path to Exile in Secret Lair x MSCHF: The Zeta Set

◇

Path to Exile received another unusual treatment in Secret Lair x MSCHF: The Zeta Set in 2026.

The Zeta Set deliberately mimics the rough, photocopied appearance of Magic's earliest internal playtest cards, giving modern cards a visual style inspired by the period before Magic reached the public.

Path to Exile was among the cards highlighted by Wizards when discussing the release, adding another radically different version to an already extensive printing history.

For collectors who prefer strange or experimental treatments, the Zeta Set Path sits at almost the opposite end of the spectrum from the polished original Conflux artwork.

ART & TREATMENTS

Path to Exile artwork, borderless cards and foils

◇

Path to Exile has an unusually broad visual range for a simple one-mana removal spell.

The Todd Lockwood Conflux original gives the card its first identity, while later releases have approached the concept through completely different characters, settings and styles.

Borderless treatments can make Path feel more like a display piece, while foil and Secret Lair versions allow players to match the card to a highly personalised Commander deck.

There is therefore no objective best Path to Exile art. The useful comparison is between the versions themselves: original, promo, traditional reprint, borderless or something much stranger.

WHICH ONE?

Which Path to Exile printing should you choose?

◇

For the original: choose the Conflux printing from 2009.

For a deck copy: compare widely available later reprints and current prices if your main priority is simply playing the card.

For classic artwork: start with Todd Lockwood's original Conflux version.

For alternative artwork: compare promotional and Secret Lair versions, including releases that reinterpret Path through completely different settings.

For a premium copy: compare foils, borderless treatments and collector-focused releases before choosing the version that fits your deck.

For something genuinely weird: the 2026 Zeta Set treatment takes Path in an intentionally rough, early-playtest-inspired direction.
